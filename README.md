🌸 FLOWER GARDEN FOR YOU 💕
============================

WHAT'S INSIDE:
- index.html  ............ the page (GitHub Pages needs this exact name)
- main.css   ............. romantic styling + floating hearts
- main.js    ............. flowers + music player
- flower-garden-ALL-IN-ONE.html ... everything in ONE file (for quick testing — just double-click it)

HOW TO TEST ON YOUR PC:
1. Double-click flower-garden-ALL-IN-ONE.html
2. Click anywhere = flowers + hearts
3. Click "Play Lover" = music (needs internet for YouTube fallback)

HOW TO PUT ON GITHUB (your live site):
1. Go to your repo: github.com/adakaominak-code/flower-garden-.0
2. Delete old index.html, main.css, main.js
3. Add file -> Upload files -> drag in: index.html, main.css, main.js
4. Commit. Wait ~1 minute. Refresh your site.

OPTIONAL BUT RECOMMENDED (best music experience):
- Get "Lover" by Taylor Swift as an MP3
- Rename it exactly: lover.mp3
- Put it in the same folder (PC) or upload to the repo (GitHub)
- Then the song plays instantly with one click. No popups!
